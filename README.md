# Bullet Bound

My first 2D game made with Unity!

## About the Game
Bullet Bound is a 2D action game featuring one playable character, enemies, and 8 challenging levels.

## Features
- 8 Levels
- One Playable Character
- Enemies
- 2D Gameplay

## Platform
- Windows PC

## About This Project
This is my first 2D Unity game project. I created it as a learning experience, and I plan to improve my future games with more features, sound, and polish.
